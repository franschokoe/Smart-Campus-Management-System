# 🎓 Smart Campus Management System (Java)

## Summary
The Smart Campus Management System is a Java-based console application designed to simulate how modern universities manage and process large volumes of campus data efficiently.

The system handles:
- Student records
- Course registrations
- Library management
- Hostel allocation
- Help desk services
- Event bookings

This project focuses on applying data structures and object-oriented programming to solve real-world problems.

---

## Objectives
- Apply data structures in real-world scenarios
- Implement custom data structures from scratch
- Design a modular and scalable system
- Strengthen object-oriented programming skills
- Simulate efficient campus data management

## Features

### Student Registry
- Add, update, delete students
- Search student records

### Course Registration
- Register students for courses
- Manage enrollments

### Library System
- Add books
- Borrow and return books

### Hostel Allocation
- Assign rooms
- Track occupancy

### Help Desk
- Submit tickets
- Process requests using queue

### Event Booking
- Create events
- Book and manage attendance
